# Product Builder To The Moon

Kanban board Next.js, construit collectivement lors d'un atelier
Git/GitHub : un socle + 7 features (une par participant·e), chacune livrée
via une pull request.

Toutes les instructions de l'atelier (setup, convention de branche, liste des
features, ordre de merge, résolution de conflits) sont dans
[`WORKSHOP.md`](./WORKSHOP.md).

## Démarrage rapide

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).
